# the-shopping-list

A simple personal shopping list app built with [Next.js](https://nextjs.org).

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Items are added, checked off, and cleared from the list; everything is
persisted to the browser's `localStorage` (`src/hooks/useShoppingList.ts`) —
there's no backend or account system yet.
